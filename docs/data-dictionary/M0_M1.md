# M0/M1/M2.0 Data Dictionary

| Area | Records | Mutability |
|---|---|---|
| Identity | `organizations`, `profiles`, `memberships` | Controlled current state |
| Authorization | `permissions`, `roles`, role/permission and membership/role grants and revocations | Definitions and grants/revocations are append-only |
| Operations | `idempotency_keys`, `outbox_events`, `outbox_delivery_receipts`, `worker_heartbeats`, `feature_flags` | Outbox/heartbeat state is controlled; delivery receipts are append-only |
| Audit | `audit_events` | Append-only |
| Content | `content_items`, `content_briefs`, `content_versions` | Item metadata is controlled; briefs and payloads are immutable |
| AI intent | `generation_jobs`, `generation_job_attempts` | Job state is controlled; attempts are append-only |
| Automated evidence | `check_definitions`, `check_runs`, `check_results` | Append-only/versioned |
| Human evidence | `scripture_evidence`, `rights_snapshots`, `review_decisions` | Append-only |
| Policy | `review_policies`, `review_policy_lanes`, `review_policy_checks` | Versioned; only active-to-inactive transition is allowed |
| Approval | `approval_snapshots`, exact review/check links, `approval_revocations` | Append-only |
| Workflow | `workflow_transitions` | Append-only |
| Export | `production_packages` | Immutable |
| Media specification | `media_output_specs` | Immutable/versioned |
| Media intent | `media_jobs` | Immutable request identity; controlled worker state |
| Media execution | `media_job_attempts` | Append-only final attempt provenance |
| Media authority | `media_artifacts` | Immutable canonical object identity, validation, and checksum metadata |
| Human media evidence | `media_reviews` | Append-only |
| Release staging | `staged_release_bundles`, `staged_release_revocations` | Append-only |
| Media recovery | `media_reconciliation_events` | Append-only operational evidence |

Every tenant-owned child carries `organization_id` and uses a composite foreign
key to its tenant-owned parent. Cross-organization references fail at the
relational layer, independently of RLS.

M0.2 outbox claims use `lease_owner`, a random `lease_token`, and
`lease_expires_at`. A stale worker cannot acknowledge after a lease is
recovered. The stable event ID and one immutable receipt form the
duplicate-delivery contract.

For generation jobs, `input_hash` is the complete request fingerprint. It
binds the brief ID, immutable brief payload hash, prompt key, and prompt
version. An exact idempotent replay returns the original job; any changed
request using the same key is rejected.

The M2.0 synthetic output specification is a mono, 16 kHz, 16-bit PCM WAV
allowlist capped at 900 seconds and 25 MiB. Canonical Storage paths are exactly
`<organization UUID>/<production package UUID>/<artifact UUID>.wav`; human
names, titles, email addresses, and content are prohibited from path
components. `storage.objects` is not an authorization authority: exact
canonical `media_artifacts` metadata and active organization membership govern
private reads.
