# STRONGR Daily Economic Target Plan

**Status:** Locked launch plan  
**Owner:** Neil Gasson  
**Recorded:** July 28, 2026  
**Current paid plan:** ChatGPT Pro, US$200/month  
**Budget boundary:** US$500-US$1,500 in additional AI-development spending from the point this plan was adopted

## Governing objective

> Reach a paid Strongr Daily launch while keeping total additional AI-development spending between US$500 and US$1,500.

Strongr OS remains the long-term platform vision, but development is temporarily constrained to work that directly helps Strongr Daily create content, launch subscriptions, enter the App Store, and begin earning revenue.

## Non-negotiable rules

1. Preserve all existing Strongr OS, Strongr Daily, Shopify, Supabase, GitHub, blueprint, migration, review, security, and content work.
2. Do not restart or broadly redesign Strongr OS.
3. Do not begin new platform milestones until the current revenue-critical gate passes.
4. Auto-reload remains off.
5. No purchased Codex credits without a specific task, written ceiling, and explicit approval.
6. Use one narrowly scoped Codex task at a time.
7. Terra is the default implementation model; Luna is for routine fixes; Sol is reserved for hard security, architecture, entitlement, and final launch gates.
8. Stop and reassess at US$500, US$1,000, and the US$1,500 hard ceiling.
9. Once paid subscriptions begin, reinvest no more than 25% of actual subscription revenue into Strongr OS development until the product is consistently profitable.
10. Features unrelated to first revenue remain postponed.

## Phase 1 - Complete the governed content engine

**Budget target:** US$0-US$200

### Required work

1. Complete the real Strongr Daily v2 Supabase acceptance run.
2. Repair only genuine failures.
3. Obtain a passing evidence artifact.
4. Create the pull request.
5. Review and merge after acceptance.

### Completion gate

Brief -> generated v2 draft -> automated checks -> human reviews -> exact-version approval -> immutable content package -> JSON and Markdown export

No new Strongr OS milestone begins until this gate passes.

## Phase 2 - Build the minimum owner Content Studio

**Budget target:** US$150-US$400

The minimum studio must allow the owner to:

- create a Strongr Daily brief;
- generate a draft;
- review all content fields;
- see automated check results;
- record Scripture, theological, and editorial reviews;
- approve the exact version;
- download the approved package;
- view prior versions.

### Completion gate

The owner can create and export one complete approved reflection from the interface without SQL or manual JSON editing.

## Phase 3 - Add one real content-generation provider

**Budget target:** US$100-US$300

The provider must:

- generate every v2 field;
- remain draft-only;
- never approve or publish;
- preserve Scripture and theological review;
- show usage or failure information;
- support controlled regeneration.

### Completion gate

Strongr OS produces a useful first draft that substantially reduces writing time while preserving human approval.

## Phase 4 - Produce the launch content reserve

**Budget target:** Primarily included Pro usage

Before subscriptions open, create approximately eight weeks of content:

- 8 guided audio reflections;
- 4 devotional experiences;
- 1 Scripture-reading series;
- prayers and personal-takeaway prompts;
- app descriptions;
- artwork prompts;
- social captions;
- metadata and release schedule.

### Completion gate

Strongr Daily has enough finished material to deliver consistent value for at least eight weeks.

## Phase 5 - Subscription and App Store launch

**Budget target:** US$150-US$500

Audit the existing Strongr Daily app before rebuilding anything. Launch-critical requirements are:

- stable production deployment;
- secure sign-in;
- paid subscription entitlement;
- monthly and annual options;
- purchase restoration;
- cancellation guidance;
- privacy policy and terms;
- account deletion;
- support contact;
- onboarding;
- App Store screenshots and listing text;
- TestFlight testing;
- App Review submission;
- launch analytics and error monitoring.

### Completion gate

A user can download Strongr Daily, subscribe, access paid content, restore a purchase, and reliably receive the promised content.
